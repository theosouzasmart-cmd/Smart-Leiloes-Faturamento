Importar notas antigas (VHSYS ou outro sistema)

Selecione os arquivos exportados: XML, PDF ou ZIP com vários deles, de qualquer empresa. A empresa é reconhecida pelo CNPJ da nota. PDF com o mesmo número ou chave do XML fica junto dele. XML sem PDF pode ganhar um PDF espelho. PDF sozinho é lido pelo texto e fica marcado para você conferir. Importar de novo os mesmos arquivos não duplica.
